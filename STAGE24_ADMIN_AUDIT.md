# Stage24 — аудит админки и настроек

База: `wakeparks-russia-stage23-map-settings.zip`.

## Что проверялось

- Наличие мест в админке для ключевых настроек проекта.
- Русификация самописных CMS-блоков и элементов шапки/подвала.
- Управление публичными формами без правки кода.
- Отображение изображений городов и парков на публичных страницах.
- Связь города и парка в каталоге.
- Настройки карты и API-ключа Яндекс.Карт.

## Что исправлено

### 1. Глобальные настройки сайта

Добавлен раздел:

```text
4. Система → Настройки сайта
```

В нём находятся:

- название проекта;
- описание проекта;
- публичный email;
- телефон;
- Telegram;
- VK;
- показ пустых городов;
- сортировка городов;
- сортировка парков;
- показ актуальности данных;
- включение/выключение публичных форм;
- honeypot;
- статусы новых парков, цен и отзывов;
- SEO по умолчанию;
- памятки для администратора.

### 2. Подключение настроек к сайту

Настройки теперь читаются публичными страницами:

- `/contacts`;
- `/cities`;
- `/wake-parks`;
- `/wake-parks/[citySlug]`;
- `/add-park`;
- `/for-parks`;
- `/update-park`;
- страница конкретного парка;
- подвал сайта.

### 3. Управление формами

Через админку можно отключить:

- форму контактов;
- форму добавления парка;
- форму отзывов;
- форму сообщения об ошибке;
- форму подтверждения владельца.

Обработчики API тоже проверяют эти настройки, поэтому отключение работает не только визуально, но и на серверной стороне.

### 4. Русификация

Переведены оставшиеся англоязычные подписи в самописных конфигурациях:

- ссылки;
- кнопки;
- первый экран;
- архивный блок;
- CTA;
- баннер;
- контентный блок;
- блок формы;
- медиа-блок;
- строки шапки и подвала;
- описания Header/Footer globals;
- описание медиафайлов.

### 5. Изображения

В проекте уже есть вывод изображений:

- `City.coverImage` выводится на `/cities` и `/wake-parks/[citySlug]`;
- `Park.cardImage` выводится в карточках и на странице парка;
- если `Park.cardImage` пустой, используется первое изображение из `Park.gallery`;
- `Park.gallery` выводится отдельным блоком на странице парка.

Где заполнять:

```text
1. Wake каталог → Города → Медиа → Изображение карточки / обложка города
1. Wake каталог → Вейк-парки → Медиа → Главное изображение карточки
1. Wake каталог → Вейк-парки → Медиа → Галерея фотографий
```

### 6. Карты

Настройки карты остались в отдельном разделе Stage23:

```text
4. Система → Настройки карт
```

Там указывается режим карты, API-ключ Яндекс.Карт, центр и масштаб.

## После установки

Открыть:

```text
/admin
```

Проверить:

```text
4. Система → Настройки сайта
4. Система → Настройки карт
1. Wake каталог → Города
1. Wake каталог → Вейк-парки
```

Если база SQLite ругнётся на новую схему global-раздела, сначала перезапустить `pnpm dev`. Если ошибка останется и это локальный тестовый MVP без важных данных — удалить SQLite-файл и запустить заново.
