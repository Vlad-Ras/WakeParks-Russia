# Wake Parks Russia — локальный MVP

Это основа агрегатора вейкборд-парков России: города → парки → карточка парка.

## Что уже добавлено

- Payload CMS на SQLite.
- Коллекция `cities` — города.
- Коллекция `parks` — вейк-парки.
- Главная страница каталога.
- Страница всех городов: `/cities`.
- Страница всех парков: `/wake-parks`.
- Страница города: `/wake-parks/[citySlug]`.
- Страница парка: `/wake-parks/[citySlug]/[parkSlug]`.
- Страница для владельцев: `/add-park`.
- Базовая навигация и текстовый логотип.

## Как запустить

```bash
pnpm install
pnpm dev
```

Сайт:

```text
http://localhost:3000
```

Админка:

```text
http://localhost:3000/admin
```

## Как добавить первый парк

1. Открой `/admin`.
2. Создай пользователя, если Payload попросит.
3. Открой раздел `Wake каталог → Города`.
4. Создай город, например `Москва`, slug `moscow`.
5. Открой `Wake каталог → Вейк-парки`.
6. Создай парк и выбери город.
7. Отметь `Опубликовано`.
8. Открой `/wake-parks/moscow`.

## Что не добавлено пока

- Интерактивная карта Яндекс/2ГИС.
- Telegram-уведомления.
- Личный кабинет владельца парка.
- Оплата/продвижение.

Эти вещи лучше добавлять следующими этапами, когда базовый каталог и модерация стабильно работают.

## Этап 2 — что добавлено

В этой версии добавлены практические функции MVP:

1. **Реальные фильтры на странице города**
   - поиск по названию, описанию, адресу и району;
   - фильтр по максимальной цене;
   - фильтр по услугам: обучение, аренда, детская школа, SUP, кафе, душ, раздевалка, парковка, пляж;
   - фильтр по типу катания: кольцевая, реверсивная, катерный вейк, лебёдка;
   - сортировка по рекомендациям, рейтингу, цене и названию.

2. **Публичная форма добавления парка**
   - страница `/add-park` теперь содержит рабочую форму;
   - форма отправляет данные в `/actions/add-park`;
   - в Payload создаётся парк со статусом `На модерации`;
   - публично парк появится только после смены статуса на `Опубликовано`.

3. **Статусы публикации**
   - добавлено поле `status`: `draft`, `pending`, `published`, `archived`;
   - старое поле `published` оставлено для совместимости с первой версией.

4. **Страница карты**
   - добавлена страница `/map`;
   - пока это список парков с адресами и ссылками на Яндекс.Карты;
   - полноценную интерактивную карту можно добавить следующим этапом.


2. Открой админку:



```powershell
# остановить pnpm dev
# удалить wakeparks-russia.db
pnpm dev
```

После удаления базы нужно заново создать администратора, города и тестовые парки.

## Этап 3 — что добавлено

   - отзывы привязаны к конкретному парку;
   - публичная форма на странице парка отправляет отзыв в `/actions/add-review`;
   - новый отзыв получает статус `На модерации`;

2. **Улучшенная страница парка**
   - добавлен блок отзывов;
   - добавлена форма отправки отзыва;
   - добавлен блок похожих парков в том же городе;
   - в правой колонке теперь выводятся дополнительные данные карточки.

3. **SEO-файлы**
   - добавлен `/robots.txt`;
   - добавлен динамический `/sitemap.xml`;
   - в sitemap попадают главная, города, каталог, карта и опубликованные страницы парков.

## Этап 4 — что добавлено

В этой версии добавлены функции, которые нужны агрегатору перед наполнением реальными данными:

1. **Интерактивная страница карты `/map` без API-ключа**
   - добавлен клиентский компонент `MapExplorer`;
   - есть поиск по названию, адресу, району и городу;
   - есть фильтр по городу;
   - при выборе парка справа открывается встроенная карта по координатам;
   - если координаты не заполнены, выводится понятная подсказка;
   - кнопки ведут в карточку парка и на маршрут в Яндекс.Картах.

2. **Глобальные фильтры на странице `/wake-parks`**
   - фильтр по городу;
   - поиск по названию, описанию, адресу и району;
   - максимальная цена;
   - услуги и инфраструктура;
   - тип катания;
   - сортировка по рекомендации, рейтингу, цене и названию.

3. **Страница `/cities` стала полезнее**
   - показывает количество городов, активных городов и опубликованных парков;
   - города с опубликованными парками поднимаются выше;
   - в карточке города показывается количество парков.

4. **Форма “Сообщить об ошибке” на странице парка**
   - добавлена коллекция `park-reports`;
   - пользователь может отправить правку по цене, контактам, адресу, графику, услугам, закрытию парка или дублю;
   - правка сохраняется в Payload со статусом `Новая`;
   - публично эти сообщения не выводятся, они нужны только администратору.

# Этап 5 — избранное и сравнение парков

В этом архиве добавлен пользовательский слой без изменения базы данных.

## Что добавлено

1. **Избранное для парков**
   - на карточках парков появилась кнопка `В избранное`;
   - на странице конкретного парка тоже есть кнопка сохранения;
   - данные сохраняются в `localStorage` браузера;
   - база SQLite не меняется, поэтому пересоздавать её только из-за этапа 5 не нужно.

2. **Страница `/favorites`**
   - показывает сохранённые парки;
   - выводит количество сохранённых парков;
   - показывает количество городов в подборке;
   - показывает минимальную цену среди сохранённых парков;
   - позволяет убрать отдельный парк или очистить всё избранное.

3. **Сравнение выбранных парков**
   - город;
   - цена;
   - рейтинг;
   - адрес;
   - типы катания;
   - услуги и инфраструктура.

4. **Навигация**
   - в верхнее меню добавлен пункт `Избранное`.

## Как проверить

1. Запусти сайт:

```powershell
pnpm dev
```

2. Открой каталог:

```text
http://localhost:3000/wake-parks
```

3. Нажми `В избранное` у нескольких парков.

4. Открой:

```text
http://localhost:3000/favorites
```

5. Проверь, что сохранённые парки отображаются и сравниваются.

## Важно

Избранное хранится только в браузере пользователя. Если открыть сайт в другом браузере, на другом устройстве или очистить данные сайта, список избранного будет пустым. Это нормально для MVP и не требует регистрации пользователей.

## Stage 7 — цены, форма добавления и SEO

Что добавлено:

1. Новая коллекция Payload **Wake каталог → Цены**.
   - Каждая цена привязывается к конкретному парку.

```text
4. Система → Подвал сайта
```

SQLite может попросить обновить схему, потому что добавлен новый global-раздел `Настройки сайта`. Сначала попробуй обычный запуск:

```bash
pnpm dev
```

Если локальная база старой версии начнёт ругаться на схему, для чистого MVP можно удалить SQLite-файл и запустить проект заново. Но сначала пробуй без удаления базы.
